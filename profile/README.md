# FastTradein


**Trade-in and buyback management software for electronics retailers.**


FastTradein helps retailers run their own device trade-in programs on their websites and in store.


Customers choose a device, answer questions about its condition and receive a preliminary estimate on the store's website. The store sets its own prices and checks the device at intake.


FastTradein brings website requests and in-store intake into one workspace, with IMEI or serial number records and revised offers by link when an inspection changes the estimate.


The store manages the customer relationship and completes each trade-in deal.
